คู่มือการนำไปใช้บน Google Sites

วิธีฝังเว็บแอปพลิเคชันลงในเว็บไซต์ Google Sites ของคุณ

Google Sites รองรับการฝังโค้ด (Embed Code)

คุณสามารถนำไฟล์ HTML นี้ไปอัปโหลดขึ้นโฮสติ้งฟรี (เช่น Netlify / Vercel / GitHub Pages) หรือใช้โค้ดฝังผ่าน HTML Box ใน Google Sites ได้ทันที

1 วิธีที่ 1: ดาวน์โหลดไฟล์เดี่ยวไปใช้ (แนะนำ)

กดปุ่มดาวน์โหลดไฟล์ HTML ด้านล่าง แล้วนำไปเปิดบนเบราว์เซอร์หรืออัปขึ้น Netlify Drag & Drop จะได้ลิงก์เว็บส่วนตัวทันที

2 วิธีที่ 2: ฝังลงในหน้า Google Sites

  1. เปิดเว็บไซต์ของคุณใน Google Sites
  2. คลิกเมนู "ฝัง" (Embed) ทางขวาของหน้าจอ
  3. เลือกแท็บ "ฝังโค้ด" (Embed Code)
  4. คัดลอก iframe หรือโค้ด HTML มาวางลงไป

สรุปรายการบริการทำส้มที่เลือก

แสดงรายการและยอดรวมของบริการทำส้มที่เลือก

ระบบคลาวด์ออนไลน์ (Online Cloud Sync)

แชร์ข้อมูลเรียลไทม์ข้ามมือถือและคอมพิวเตอร์หลายเครื่อง

สถานะการเชื่อมต่อ: เชื่อมต่อคลาวด์แล้ว

เมื่อคุณกรอกข้อมูล เพิ่มบิล หรือแก้ไขเบอร์ส้ม ข้อมูลจะถูกอัปเดตและบันทึกลงฐานข้อมูลออนไลน์ (Cloud Server) อัตโนมัติ ทำให้เครื่องอื่นที่เปิดหน้านี้เห็นข้อมูลตรงกันทันที

ใช้รหัสนี้ร่วมกันในเครื่องพนักงานท่านอื่นเพื่อดูข้อมูลและบันทึกบิลชุดเดียวกัน

โหมดออฟไลน์ (Offline Mode)

ระบบบันทึกและทำงานได้โดยไม่ต้องใช้อินเทอร์เน็ต

ทำงานแบบออฟไลน์ได้ 100%

แอปพลิเคชันนี้ถูกออกแบบมาให้เก็บข้อมูลทั้งหมดไว้ในหน่วยความจำเบราว์เซอร์ของคุณ (LocalStorage) โดยอัตโนมัติ คุณสามารถบันทึกข้อมูล ดูบิล พริ้นท์รายงาน และคำนวณเบอร์ส้มได้ทันทีแม้ไม่ได้เชื่อมต่ออินเทอร์เน็ต

ยืนยันล้างข้อมูลทั้งหมด

คุณแน่ใจหรือไม่ว่าต้องการลบข้อมูลบันทึกบริการและบิลทั้งหมดออกจากระบบ? แนะนำให้สำรองข้อมูล (Export JSON) ไว้ก่อนดำเนินการ

คู่มือการนำไปใช้บน Google Sites

วิธีฝังเว็บแอปพลิเคชันลงในเว็บไซต์ Google Sites ของคุณ

Google Sites รองรับการฝังโค้ด (Embed Code)

คุณสามารถนำไฟล์ HTML นี้ไปอัปโหลดขึ้นโฮสติ้งฟรี (เช่น Netlify / Vercel / GitHub Pages) หรือใช้โค้ดฝังผ่าน HTML Box ใน Google Sites ได้ทันที

1 วิธีที่ 1: ดาวน์โหลดไฟล์เดี่ยวไปใช้ (แนะนำ)

กดปุ่มดาวน์โหลดไฟล์ HTML ด้านล่าง แล้วนำไปเปิดบนเบราว์เซอร์หรืออัปขึ้น Netlify Drag & Drop จะได้ลิงก์เว็บส่วนตัวทันที

2 วิธีที่ 2: ฝังลงในหน้า Google Sites

  1. เปิดเว็บไซต์ของคุณใน Google Sites
  2. คลิกเมนู "ฝัง" (Embed) ทางขวาของหน้าจอ
  3. เลือกแท็บ "ฝังโค้ด" (Embed Code)
  4. คัดลอก iframe หรือโค้ด HTML มาวางลงไป
